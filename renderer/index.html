⚙ Ustawienia
Konto SMTP (wysyłka e-maili)
Dla Gmail: włącz weryfikację dwuetapową, wejdź w Konto Google → Bezpieczeństwo → Hasła do aplikacji i wygeneruj hasło dla "Poczta".
💡 Wieloma kontami Gmail zarządzasz w zakładce Konta — tam przełączysz konto jednym kliknięciem.
☁️ Supabase (stały serwer)
Stały serwer w chmurze: śledzenie napraw, formularz reklamacji ze strony WWW i zdjęcia z telefonów działają zawsze — nawet przy wyłączonym komputerze. Dane z panelu supabase.com: Project Settings → API (adres projektu i klucz service_role).
✅Połączono
Gdy Supabase jest ustawiony, adres publiczny ustawia się sam — pola niżej zwykle zostaw puste.
Integracja Apilo
Pozwala importować dane klienta z zamówień Allegro/marketplace podczas przyjmowania reklamacji. Klucze znajdziesz w panelu Apilo: Administracja → Klucze API Apilo.
✅Połączono
Jednorazowo: wygeneruj Kod autoryzacyjny w Apilo (Klucze API → Generuj kod) i wpisz poniżej. Po połączeniu token odświeża się automatycznie.
🔑 Klucze API (własne API)
Zewnętrzne systemy mogą tworzyć i pobierać zlecenia przez REST API. Endpoint: …/api/v1/ 📄 Dokumentacja
📦 Sklep — zamówienia części
Adres email dostawcy/sklepu, na który mechanicy będą wysyłać zamówienia brakujących części jednym kliknięciem.
🛒 Allegro (integracja)
Client ID i Client Secret z panelu apps.developer.allegro.pl. Po podaniu kluczy kliknij "Połącz z Allegro" — otworzy się przeglądarka do zalogowania.
✅Połączono
🏪 Shoper (integracja)
W panelu Shoper załóż konto administratora z dostępem do WebAPI (Konfiguracja → Administracja, system → Administratorzy) i wpisz jego login oraz hasło. Zamówienia ze sklepu zobaczysz w zakładce Sklep — jednym kliknięciem zrobisz z nich zlecenia.
