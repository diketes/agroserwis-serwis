⚙ Ustawienia e-mail
Konto SMTP (wysyłka e-maili)
Dla Gmail: włącz weryfikację dwuetapową, wejdź w Konto Google → Bezpieczeństwo → Hasła do aplikacji i wygeneruj hasło dla "Poczta".
Publiczny adres serwera
Link w e-mailu musi być dostępny z internetu. Zostaw puste jeśli klienci są w tej samej sieci co komputer warsztatu (lokalny adres IP). Jeśli chcesz dostęp z zewnątrz — wpisz publiczne IP lub domenę, np. http://1.2.3.4:3737
Integracja Apilo
Pozwala importować dane klienta z zamówień Allegro/marketplace podczas przyjmowania reklamacji. Klucze znajdziesz w panelu Apilo: Administracja → Klucze API Apilo.
✅Połączono
Jednorazowo: wygeneruj Kod autoryzacyjny w Apilo (Klucze API → Generuj kod) i wpisz poniżej. Po połączeniu token odświeża się automatycznie.
